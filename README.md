# 🐍 Responsive Snake Game

This is a web-based Snake game built from scratch using HTML, CSS, and TypeScript. It features a responsive layout that automatically adjusts to fit any screen size perfectly, along with clean object-oriented code.

---

## ✨ Features

* **HTML & CSS View:** Uses HTML Canvas for rendering the game grid and CSS for centering and responsiveness.
* **TypeScript Logic:** Built using strict TypeScript classes and enums to manage the snake's movement, directions, and score tracking.
* **Collision Detection:** Automatically detects when the snake hits the wall boundaries or crashes into its own body, triggering a "Game Over" alert.
